AI-Based Ransomware Intrusion Detection System

  • A Flask-based real-time IDS that combines live packet analysis, an ML network-flow classifier and a file-system ransomware monitor, all streaming to a live web dashboard.
  • Captures packets with Scapy and aggregates flows; Isolation Forest flags anomalies and a Random Forest trained on CICIDS2017 classifies DDoS traffic, plus port-scan detection and feature-importance analysis.
  • Watches the file system for ransomware behaviour, and falls back to heuristic detection if the model is missing.
  • Pitched at CUNY PitchFest 2026 with my capstone team.

Regodit: Evidence-First AI Security Analyst

  • An AI analyst that completes vendor-security questionnaires by searching company policies, SOC 2 and VAPT reports, contracts and infrastructure records first, citing a stable evidence ID for every claim.
  • Covered 66 items across 14 control domains (IAM, incident response, vulnerability management, data security, third-party risk), with conflict detection and confidence scoring.
  • Asks one focused follow-up when evidence runs out, and flags contradictions instead of smoothing them over. Policy intent never counts as proof of implementation.
  • Built on LangGraph and OpenAI structured outputs. Tracing with Block Convey PRISM exposed an LLM omission hiding an MFA policy/implementation conflict, which we fixed (98.89 trajectory score).
  • Built with Nikisha Roberts, Shakthi Shyam and Akshay Atam.

MS Cybersecurity, CCNY · Applied Cryptography

Threshold ElGamal Encryption

  • A (t+1)-out-of-n threshold ElGamal scheme: any t+1 of n players can decrypt together, and the secret key is never reconstructed in memory.
  • Splits the private key with Shamir Secret Sharing and uses hybrid ElGamal + AES encryption.
  • Includes a GUI app that walks through two-phase threshold decryption.

Secure ATM System (TriHackers)

  • A secure ATM system for a fictional "Big Bank", built in Rust by team TriHackers, with three roles: customers, teller admins and cash handlers.
  • PIN authentication, role-based access control, daily withdrawal and deposit limits, denomination-level cash management, and full transaction logging on SQLite (sqlx) with parameterized queries.
  • Aligned with the OWASP Top 10 and CWE; we ran adversarial testing, including backdoor injection analysis, and fixed what we found.
